# 🕸️ Networkwalks - Cybersecurity Projects | Week 1

**Hands-on Cybersecurity Lab Setup • Network Traffic Analysis • Security Investigation**

## Overview

This repository documents my practical learning and cybersecurity exercises completed during **Week 1 of my cybersecurity internship at Networkwalks**.

The projects focus on building a virtual cybersecurity lab, understanding network configurations, analyzing captured network traffic, and investigating patterns associated with potential security threats.

The repository combines foundational lab setup with practical network investigation exercises to strengthen my understanding of cybersecurity tools and techniques.

---

## 🔹 Projects

### 🛡️ Project 1: Cybersecurity Lab Setup – Kali Linux

**Focus:** Virtualization, Linux networking, connectivity verification, and troubleshooting.

Configured a virtual cybersecurity environment using Oracle VirtualBox and Kali Linux.

**Key Activities**
- Configured a Kali Linux virtual machine and its system settings.
- Enabled shared-folder integration, clipboard sharing, and drag-and-drop functionality.
- Configured NAT networking and explored IPv4 addressing and network interfaces.
- Verified internet connectivity and DNS resolution using Linux commands.
- Verified Nmap availability and created a virtual machine snapshot.
- Investigated network configuration and connectivity issues.

📂 **[Explore the Cybersecurity Lab Setup](01-MAIN-PROJECT-CYBERSECURITY-LAB-SETUP/README.md)**

### 🦈 Project 2: Wireshark – Network Traffic Analysis and SOC Labs

**Focus:** Packet inspection, protocol analysis, and investigation of potentially suspicious network activity.

Completed six hands-on Wireshark labs covering different aspects of network traffic analysis.

**Key Activities**
- Identified a suspected attacker's IP address from captured traffic.
- Reconstructed and inspected TCP conversations using Follow TCP Stream.
- Examined HTTP traffic to understand plaintext credential exposure.
- Investigated patterns associated with potential brute-force activity.
- Analyzed SIP/RTP traffic related to communication sessions.
- Used packet inspection and display filters to investigate relevant network activity.

## Key Learning Outcomes

- **Cybersecurity Lab Management:** Configuring and maintaining a virtual Linux environment.
- **Networking Fundamentals:** Understanding IP addressing, network interfaces, NAT, and DNS resolution.
- **Packet Analysis:** Inspecting captured traffic and investigating network communication.
- **Protocol Analysis:** Examining TCP, HTTP, SIP, and RTP traffic.
- **Security Investigation:** Exploring traffic patterns that may indicate suspicious activity.
- **Troubleshooting:** Investigating connectivity and network configuration issues.
- **Technical Documentation:** Recording practical work, screenshots, findings, and key learnings in GitHub.

## Relevance to SOC Operations

Network visibility and packet analysis are valuable skills in Security Operations Center (SOC) environments. Analysts use network evidence to investigate suspicious connections, examine potential credential exposure, review unusual authentication activity, and support incident investigations.

These projects provided foundational hands-on experience with cybersecurity lab configuration and network traffic investigation.
